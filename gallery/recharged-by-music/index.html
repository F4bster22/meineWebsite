Musik auf Play und die Welt auf Pause

Musik kann einem unglaublich viel geben. Sie kann trösten, sie kann motivieren, sie kann zum Lachen bringen und manchmal auch zum Weinen. Für viele Menschen ist sie mehr als nur eine Aneinanderreihung von einzelnen Tönen.

Dieses Bild ist eine Anlehnung an eine Benzin-Zapfsäule, weil Musik für manche Menschen wie Treibstoff wirkt. Kopfhörer auf, Musik an und für einen kurzen Moment wird die Welt leiser.
